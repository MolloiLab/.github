<h1 align="center">MolloiLab</h1>

<p align="center">
  <b>Imaging Physics Laboratory · University of California, Irvine</b><br>
  Open tools for simulating and quantifying CT.
</p>

<br>

| Tool | What it does |
|---|---|
| **[Vasculature.jl](https://molloilab.github.io/Vasculature.jl/getting-started/)** | Grows vascular networks inside anatomy, solves their flow, carries contrast through them and writes voxel phantoms. [Repository](https://github.com/MolloiLab/Vasculature.jl) |
| **[BasisSimulator.jl](https://molloilab.github.io/BasisSimulator.jl/getting-started/)** | Polychromatic CT simulation and reconstruction, energy-integrating and photon-counting, on an NVIDIA or Apple GPU or on the CPU. [Repository](https://github.com/MolloiLab/BasisSimulator.jl) |
| **[DistanceTransforms.jl](https://molloilab.github.io/DistanceTransforms.jl/)** | Fast distance transforms on the GPU. [Repository](https://github.com/MolloiLab/DistanceTransforms.jl) |
| **[hpc3-onboarding](https://github.com/MolloiLab/hpc3-onboarding)** | Getting started on UCI's HPC3 cluster, step by step. |
| **[hpc3-launcher](https://github.com/MolloiLab/hpc3-launcher)** | A desktop launcher for HPC3: jobs, node status and remote editors. |
