# MolloiLab

The Imaging Physics Laboratory at the University of California, Irvine. We build open tools for
simulating and quantifying medical imaging, mainly CT.

| Package | What it does |
|---|---|
| [Vasculature.jl](https://github.com/MolloiLab/Vasculature.jl) · [docs](https://molloilab.github.io/Vasculature.jl/) | Grows vascular networks inside anatomy, solves their flow, carries contrast through them and writes voxel phantoms. |
| [BasisSimulator.jl](https://github.com/MolloiLab/BasisSimulator.jl) · [docs](https://molloilab.github.io/BasisSimulator.jl/) | Polychromatic CT simulation and reconstruction, energy-integrating and photon-counting, on an NVIDIA or Apple GPU, or on the CPU. |
| [DistanceTransforms.jl](https://github.com/MolloiLab/DistanceTransforms.jl) · [docs](https://molloilab.github.io/DistanceTransforms.jl/) | Fast, GPU-accelerated distance transforms. |
| [hpc3-launcher](https://github.com/MolloiLab/hpc3-launcher) | A desktop launcher for UCI's HPC3 cluster: jobs, node status and remote editors. |
| [hpc3-onboarding](https://github.com/MolloiLab/hpc3-onboarding) | Getting started on HPC3, step by step. |
